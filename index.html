About

Hey — I'm Namish Dawar, a Class X student from Gurugram with a deep interest in robotics, embedded systems, and software development. I build hands-on STEM and programming projects involving Arduino-based systems, NodeMCU IoT applications, and modern web interfaces.

My flagship project — the Parkinson's Self-Stabilizing Spoon — earned 1st Runner-Up at KVRSS India in the Physics category. It's an Arduino-powered device with gyroscopic stabilization to counteract hand tremors, helping people eat independently.

I've also worked in collaborative, time-bound development environments building web prototypes with React and JavaScript — experiences that sharpened my problem-solving, adaptability, and ability to ship under pressure.

My approach is simple: learn by building — system design, clean implementation, debugging, and practical problem-solving. Always curious, always making something.
