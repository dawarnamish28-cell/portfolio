About Me

Hey! I'm Namish Dawar, a Class X student from Gurugram with a deep passion for robotics, embedded systems, and software development. I build hands-on STEM and programming projects involving Arduino-based systems, NodeMCU IoT applications, and modern web interfaces.

My flagship project — the Parkinson's Self-Stabilizing Spoon — earned 1st Runner Up at KVRSS India in the Physics category. It's an Arduino-powered device with gyroscopic stabilization to counteract hand tremors, helping Parkinson's patients eat independently.

I've worked in collaborative, time-bound development environments building web prototypes using React and JavaScript. These experiences sharpened my problem-solving approach, adaptability, and ability to ship real products under pressure.

My philosophy is learning through building — system design, clean implementation, debugging, and practical problem-solving. Always curious, always building.
